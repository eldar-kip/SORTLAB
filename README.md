# SORTLAB — Лаборатория алгоритмов сортировки

> **«Изучай алгоритмы. Наблюдай за каждым шагом. Сравнивай эффективность».**  
> Интерактивное образовательное веб-приложение по дисциплине **«Алгоритмы и структуры данных»**.

---

## Технологический стек

- **React 18 + TypeScript** — компонентная архитектура и строгая типизация
- **Vite 5** — сборщик и локальный сервер приложения
- **Tailwind CSS 3** — кастомная дизайн-система в тёмной лабораторной палитре (`#0B0D12`, `#121620`, `#171D29`, `#8B5CF6`, `#06B6D4`)
- **Recharts** — графики сравнения производительности и кривых роста сложности Big O
- **Lucide React** — иконки интерфейса
- **React Router v6** — маршрутизация по 9 разделам приложения
- **Vitest** — модульное тестирование всех 8 алгоритмов и валидации данных
- **Docker & Docker Compose** — локальный запуск в контейнере (`node:20-alpine`)

---

## Быстрый запуск через Docker

### 1. Запуск локального контейнера (порт `5173`)
```bash
docker compose up -d
```
После запуска откройте в браузере: **http://localhost:5173**

### 2. Запуск автоматических тестов внутри контейнера
```bash
docker compose exec sortlab npm test
```

### 3. Остановка контейнера
```bash
docker compose down
```

## Локальный запуск (при установленном Node.js 20+)

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Запуск тестов
npm test

# Сборка проекта
```

## Реализованные алгоритмы сортировки

1. **Bubble Sort** — сортировка пузырьком (с оптимизацией раннего завершения)
2. **Selection Sort** — сортировка выбором
3. **Insertion Sort** — сортировка вставками
4. **Merge Sort** — сортировка слиянием (с визуализацией подмассивов и глубины рекурсии)
5. **Quick Sort** — быстрая сортировка (с выбором из 4 стратегий опорного элемента: средний, медиана из трёх, последний, первый)
6. **Heap Sort** — пирамидальная сортировка (с интерактивным деревом двоичной кучи `i → 2i+1, 2i+2`)
7. **Shell Sort** — сортировка Шелла (с подсветкой шага `gap` и подгрупп)
8. **Counting Sort** — сортировка подсчётом (с поддержкой отрицательных чисел и таблицей частот `count`)
